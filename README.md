# BuildMart Admin Dashboard

Dashboard admin untuk website jualan **material bangunan** dan **properti**.

## Fitur

- Ringkasan KPI: penjualan, pesanan, SKU material, listing properti, stok menipis, leads
- Grafik tren penjualan material vs properti
- Distribusi kategori material
- Tabel pesanan terbaru
- Alert stok menipis
- Daftar listing properti dengan views & leads
- Sidebar navigasi (halaman lain placeholder)

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:5173

## Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4
- Recharts
- Lucide Icons
